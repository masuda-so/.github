# .github

[日本語](#github) | [English](#about-this-repository)

Ether合同会社の公開リポジトリ共通の[コミュニティヘルスファイル](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)を置くリポジトリです。各リポジトリに同名のファイルがない場合、ここにあるファイルが既定として使われます。

| ファイル | 役割 |
|---|---|
| `CODE_OF_CONDUCT.md` | 行動規範（Contributor Covenant 2.1） |
| `CONTRIBUTING.md` | 貢献手順 |
| `SECURITY.md` | セキュリティポリシーと脆弱性の報告方法 |
| `SUPPORT.md` | サポート窓口 |
| `.github/ISSUE_TEMPLATE/` | Issue テンプレート |
| `.github/PULL_REQUEST_TEMPLATE.md` | Pull Request テンプレート |

ライセンスファイルは既定にできないため、各リポジトリに個別に置いています。

## About this repository

This repository holds the default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) shared by the public repositories of Ether LLC. A repository without its own file of the same name uses the one here.
