## サポート対象のバージョン

修正は、各アプリとサービスの最新リリース、および各リポジトリの`main`ブランチに対して行います。

## 脆弱性の報告

脆弱性を見つけた場合は、公開のIssue、Pull Request、Discussionには書かず、GitHubの非公開の報告機能を使ってください。

1. 該当するリポジトリの「Security」タブを開きます。
2. 「Report a vulnerability」を選びます。
3. 影響を受ける箇所、再現手順、想定される影響を記入して送信します。

報告には、原則として5営業日以内に一次返信します。修正の公開までは、内容を非公開のまま扱います。修正後、報告者の希望に応じて謝辞を記載します。

## Security policy

This policy covers the public repositories of Ether LLC listed above.

Fixes are made to the latest release of each app or service and to the `main` branch of each repository.

Do not report vulnerabilities in public issues, pull requests, or discussions. Use GitHub private vulnerability reporting instead: open the **Security** tab of the affected repository, choose **Report a vulnerability**, and describe the affected component, steps to reproduce, and the expected impact.

We aim to send a first response within five business days and keep the report private until a fix is published.
